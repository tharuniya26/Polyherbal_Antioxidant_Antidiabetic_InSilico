## Reference identity, structures and chemical states

The validator queried official PubChem PUG REST for the three CIDs and compared formula and isomeric molecular graph to the existing library and every source SDF record. The reference records were [rutin CID 5280805](https://pubchem.ncbi.nlm.nih.gov/compound/5280805), [luteolin CID 5280445](https://pubchem.ncbi.nlm.nih.gov/compound/5280445) and [quercetin CID 5280343](https://pubchem.ncbi.nlm.nih.gov/compound/5280343). Rutin is **C27H30O16**, 43 heavy atoms, ten defined stereocentres and two linked sugar rings; luteolin is **C15H10O6**, 21 heavy atoms and no stereocentres; quercetin is **C15H10O7**, 22 heavy atoms and no stereocentres. Every source record matched its reference isomeric graph, formula, charge, three-dimensional implied stereochemistry, explicit hydrogen requirement, finite MMFF94s energy and basic bond/nonbonded geometry. These checks establish a *chosen PubChem reference*, not the exact stereochemical identity of each literature peak.

All **60 rutin**, **24 luteolin** and **24 quercetin** SDF records were checked. The source SDF SHA256 values are respectively `eda5ee9e8251654ac703dee9d9812b3e9b39d29897917a0ae0b0396b82ceccf2`, `49f6e821cc442011482b9b6d21e66c409898bba6b9fe109522fa3f94009be0a8`, and `aad6f102775cb6076bc26abc7ef50717255f8da6ad1fc2f10379c7e53b4d6362`. Original neutral PDBQTs passed Meeko 0.8.0 to RDKit graph/stereo readback, complete heavy-atom index maps, finite coordinates, correct torsion counts and net partial-charge tolerance: rutin **16 torsions, +0.001**, luteolin **5, +0.001**, quercetin **6, −0.001**. Rutin's new record-specific PDBQTs and one-record SDFs were written only under [`structures/ligands/vina_prepared/alternative_3L4W/`](../../structures/ligands/vina_prepared/alternative_3L4W/); the manifest records every file hash and mapping. The reused quercetin 4′-O monoanion file has a validated **−1 formal charge and −1.002 summed PDBQT charge**; its source and readback were checked against the [previous frozen input manifest](../../data/metadata/vina_3L4W_pilot_input_manifest.csv).

For luteolin, the neutral phenolic/keto graph is an explicit reference hypothesis. Published aqueous acid-base work reports a first dissociation around the near-neutral-to-weakly-basic range, with disagreement about the assigned first phenolic site across methods ([aqueous spectroscopic study](https://pmc.ncbi.nlm.nih.gov/articles/PMC9614196/), [aqueous potentiometric/spectrophotometric study](https://doi.org/10.3390/app13020776)). This does **not** justify choosing an arbitrary 4′-O or 7-O phenolate for a frozen pH-6.5 docking comparison. The neutral luteolin input passes; anion site selection remains on hold. Rutin has multiple phenolic sites and method-dependent acid dissociation; the neutral reference passes, while any anion needs a named site and separate source-based preparation. Quercetin's prior 4′-O monoanion is a documented model supported by the [prior pilot plan](vina_3L4W_phytochemical_pilot_plan.md), not a measured bound-state population. Standard Vina's treatment of supplied partial charges limits any neutral-versus-anion physical interpretation. None of these input choices proves the in-pocket protonation state.

## Deterministic conformer and rigid-core freeze

Rutin's 60 MMFF94s conformers were screened **without docking scores**. From those within 12.0 kcal/mol of the stored pool minimum, a deterministic max–min, symmetry-aware fitted heavy-atom RMSD rule selected **one-based SDF records 1, 3, 4, 5 and 9**. Their stored energies are **218.318807, 223.983880, 224.318309, 224.433297 and 228.481420 kcal/mol**; the minimum pairwise fitted heavy-atom RMSD is **2.04 Å**. These MMFF numbers order isolated conformers *within this one chemical state*; they are not binding energies. This five-member set samples different initial shapes but does not establish adequate sampling of a **16-torsion** glycoside. A failure to converge later would require an explicitly planned conformer-coverage investigation, never post hoc replacement by favorable starts.

Luteolin uses existing lowest-energy **record 1** for all five seeds because its flavone scaffold is much less flexible; independent starting orientations and translations test the search. Existing quercetin neutral and 4′-O monoanion files, atom maps and earlier starts are reused; **20 original-box and 20 enlarged-box quercetin run records and their receptor, ligand, start, output and log hashes were checked**. The old enlarged-box 4′-O monoanion/Asp542H combination retained its 5/5 geometric PASS; the other quercetin combinations remained INCONCLUSIVE. Those are results of the same molecule in the prior Senna-labelled pilot and must not be counted again as a new Boerhavia experiment.

The rigid-core maps are molecule-specific, one-based SDF indices with the corresponding Meeko PDBQT serials in the manifest. For rutin they are the **17-atom three-ring quercetin aglycone scaffold plus its carbonyl oxygen**; for luteolin, the **17-atom three-ring flavone scaffold plus carbonyl oxygen**. The rutin sugar atoms are deliberately excluded from *rigid-core* RMSD but included in all-heavy pocket, clash and box checks. Quercetin retains its **previously frozen chromone-based core map**. Graph automorphisms must be applied only where the verified parent graph permits them, and RMSD must be computed without independently fitting poses in the receptor frame.

Five new, seed-specific, rigidly randomized PDBQT starts per new molecule are frozen under [`docking/pilot/vina/3L4W_alternative_input_starts/`](../../docking/pilot/vina/3L4W_alternative_input_starts/). Rutin uses one selected conformer per seed, in record order 1/3/4/5/9. Luteolin uses record 1 with five independent rigid transforms. The *same start file per seed* is to be used against both receptor microstates. Rutin's minimum observed box-face margin among frozen starts is **1.614 Å** and luteolin's is **5.064 Å** after PDBQT rounding. All starts passed readback and preserved pairwise heavy-atom geometry within 0.002 Å. Different rutin conformers are paired with different seeds, so conformer and random-search effects cannot later be separated from this five-run pilot alone.

Both existing, dry/no-NAG 3L4W receptors were hash-checked: Asp443−/Asp542−/His600-HID, SHA256 `7a76e0fa3b7bf2197714a57a88c60d2f4eefedccb18636951f3f643473afadf3`; and Asp443−/Asp542H(OD2)/His600-HID, SHA256 `220e3585558e4bc261e6e76ddb036738dea827543e1b135399506e95ea9f93fd`. The control CSV SHA256 is `9626a145b87c6429e15fd352c53add96e31c9bdb4a3ec3fccc9d058bee7fed09`. No native-MIG run was repeated.

For a later separately authorized search, use the supported **30 × 24 × 24 Å** box centered at **(45.38664286, 92.35157143, 34.82200000) Å**, Vina 1.2.7 `vina` scoring, exhaustiveness 64, 20 modes, energy range 5.0, minimum RMSD 1.0 Å, one CPU and seeds **1101, 2202, 3303, 4404, 5505**. Do not change chemistry or the box after viewing results. Receptor and frozen-start *geometry* are compatible, but this step did not run a Vina parse or grid test; require one before initiating any new searches. The previously frozen screen remains: all heavy atoms inside the box; rigid-core centroid ≤6.0 Å from deposited MIG; at least half of core atoms ≤4.0 Å from a MIG atom; no ligand–receptor pair <1.8 Å or van-der-Waals overlap >0.8 Å; no nonbonded internal heavy-atom pair <1.6 Å; box-face margin <1.0 Å reported as a warning. Within **each microstate and receptor state**, ≥4/5 rank-1 poses must also meet pocket and clash rules and lie within **2.0 Å unfitted core RMSD** of that state's medoid. Report every seed, mode, error and alternative pose. A geometric PASS is not biological validation.
